🎮 MyPS2 File Manager

Свой файловый менеджер и загрузчик игр для PlayStation 2

📖 О проекте

Минималистичный файловый менеджер для PS2, написанный на C с использованием PS2SDK. Позволяет просматривать файлы на USB-флешке, запускать ELF-приложения и скачивать игры прямо с HTTP-сервера через Ethernet.

✨ Возможности

  • Просмотр файлов и папок на USB (FAT32)
  • Запуск ELF-приложений прямо из меню
  • Скачивание игр с HTTP-сервера по сети
  • Показ размера файлов
  • Удаление файлов
  • Запуск скачанных игр сразу после загрузки
  • Навигация с геймпада (D-Pad)

🚀 Как установить

1. Скопируйте myFileMan.elf на USB-флешку (FAT32).

2. Вставьте флешку в PS2.

3. Запустите через uLaunchELF или FMCB.

4. В программе нажмите правую стрелку для перехода к списку игр с сайта.

5. Выберите игру и нажмите X для скачивания.

🛠️ Сборка

Проект собирается с использованием PS2SDK:

git clone https://github.com/USERNAME/myFileMan.git
cd myFileMan
make clean
make

Результат — файл myFileMan.elf.

📄 Управление

  • D-Pad ↑↓ — навигация
  • X — запустить ELF / войти в папку
  • O — выйти в родительскую папку
  • SELECT — удалить файл
  • → — переключиться на список с сайта
  • ← — вернуться к локальным файлам
  • START — выход
